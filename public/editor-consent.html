Installing on Duda

1. Save, then use Get embed code above.
2. In Duda: Site Settings → Site Header HTML — paste the tag above any analytics code so tracking waits for consent.
3. Turn off Duda's built-in cookie notification (Site Settings → Privacy) so visitors see one banner, not two.
4. Wrap any non-Google tracker as <script type="text/plain" data-tg-consent="analytics"> and it stays dormant until consent.
