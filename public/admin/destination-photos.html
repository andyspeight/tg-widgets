Destination photos

Fills the hero photo for destinations that have none, three landscape photos per record with a credit line each, the same way the countries were filled. Only records with an empty Images field are touched. Run a dry run first to see the photos a batch would choose.

The deployment has no UNSPLASH_ACCESS_KEY, so nothing can be fetched yet. Add it in Vercel (Settings, Environment Variables) and redeploy, then come back here.
