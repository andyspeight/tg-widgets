Top 10 Destinations

A ready-made ranked list, drawn live from our destination content base. Every agency starts from one of eight curated lists and can reorder it, swap entries or rewrite the heading in the editor. The photos, taglines, best months and flight times are never copied into the widget, they are read live, so a correction to the content base reaches every embedded list.

    The ranking is editorial, and it says so. Nothing in the destination database ranks one
    place above another, so this widget never pretends to compute a Top 10. It renders the order
    it is given, which is either the curated order we ship or the order the agency dragged the
    entries into. Each entry can link straight through to the agency's own destination page using
    their URL pattern, so the list feeds their site rather than leading away from it.
