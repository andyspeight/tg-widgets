        Why the first check is the one that matters

        Everything else is downstream of it. Schema, headings, reviews, none of it counts for anything if the crawler never reaches the page.

        • Bot protection is on by default

          Cloudflare's Bot Fight Mode is switched on for new domains and it turns AI retrieval bots away at network level. Nobody gets told. Your site looks perfectly healthy in a browser.

        • We prove it rather than guess

          A browser request runs first on every check. If a crawler is refused and the browser was not, that is a block and we say so. If both are refused we say inconclusive, because anything else would be a guess dressed up as a finding.

        • Then we fix it

          Other tools stop at the report. We build and run the sites, so the fixes can be done rather than just listed.
